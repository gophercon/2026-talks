# Safer Agent Infrastructure - Marc Dougherty, Google

## Talk Description

AI agents today are desktop software, acting directly with a user's credentials.
This has led to auth token leaks and unexpected behaviors that reach the news.
How can you avoid making the headlines? Better authentication, and management of
delegated credentials is the first step. Learn some tactics for keeping the keys
away from your agents, and other ways to make your agent infrastructure more
mature (and a bit safer!).

## Speaker Info

Marc is the Developer Relations Lead for Go at Google. Before joining the Go
team, Marc worked as a Site Reliability Engineer (SRE), giving him a passion for
building distributed systems with a focus on resilience and observability.
