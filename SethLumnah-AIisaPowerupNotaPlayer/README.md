# AI is a Power-up, Not a Player - Seth Lumnah, Capital One

## Abstract

I maintain shared Go libraries used across a large organization, and the bottleneck has never been code—it's attention. Proposals pile up, PRs wait for review, and community updates never get written because compiling them takes too long. So I started writing agent skills: markdown files that point an AI at our style guide and tell it how to handle routine work. This talk tours the skills I actually use, the discipline that keeps reviews honest, and the foundation work that any maintainer can start tomorrow. AI is a power-up, not a player.

## Speaker Info

Seth has been a software engineer at Capital One since 2020. He has worked on several major Go-based projects, serves as a Go language lead, and maintains the company's internal Go shared libraries. Seth volunteers as a steward of the Go Community of Practice at Capital One and is passionate about building a feature-rich Go ecosystem.
