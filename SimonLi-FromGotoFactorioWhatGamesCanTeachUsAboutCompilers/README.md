# From Go to Factorio: What Games Can Teach Us About Compilers - Simon Li, Meta

## Talk Description

Go's compiler quietly transforms every program into a form most developers never see.
What if you could not just see it, but play with it?
This talk turns a hidden layer of Go into a living, ticking factory.
The factory must grow.

## Speaker Info

Simon is a Software Engineer working on the Go Foundation Team at Meta.
He focuses on developer experience, infrastructure, and tooling, with a background in platform engineering using Kubernetes, cloud networking, and Go.
