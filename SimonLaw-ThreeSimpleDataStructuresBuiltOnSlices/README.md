# Three Simple Data Structures Built on Slices - Simon Law, Tailscale

## Talk Description

The humble slice is a familiar friend to any Go programmer.
But did you know that you can build stacks, circular queues, and priority queues on top of a slice from memory?
Amaze your friends and impress your colleagues as you do a little typing instead of importing a little dependency.

## Speaker Info

Simon is a software developer at Tailscale,
where engineers fearlessly spin up custom internal tools since it’s fast, secure, and easy.
Before Tailscale,
he has helped software teams wire custom automations to their Salesforce instances,
operated and secured one of the world’s largest HBase deployments,
and started Developer Tools teams at multiple startups.
