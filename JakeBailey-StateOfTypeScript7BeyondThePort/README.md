# State of TypeScript 7: Beyond the Port - Jake Bailey, Microsoft

## Talk Description

Last year, we shared the story of TypeScript's port to Go. A lot has happened since then: we've shipped TypeScript 6.0 as a bridge release and watched our native preview grow past 5 million weekly downloads. The port is done, but the work didn't stop there.

In this talk, we'll go beyond the port itself. We'll cover the new API surfaces we've built on top of the Go codebase, including a snapshot-based language server, cross-language IPC, and Wasm. We'll talk about how the community has adopted the new compiler, how we've ensured stability at scale, and what surprises and compromises came up along the way. We'll also share our continued experience writing Go: where the language and toolchain have gotten better for us, and where they sometimes haven't.

## Speaker Info

Jake Bailey is a Principal Software Engineer at Microsoft working on TypeScript.
